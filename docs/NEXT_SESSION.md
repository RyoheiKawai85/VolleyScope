# 次回作業：TrackNetV3 Epoch 3のFN原因分析

## 現在地

TrackNetV3公開重みから、バレーボール用データによる3 epoch追加学習を完了した。

公式Datasetの座標配列が反復走査で破壊的に変更される問題を確認し、各train・val走査前に新しいDatasetを生成することで回避した。

修正版3 epoch実験と、Epoch 3の独立再評価は同じ結果になった。

### 公開重みbaseline

- TP：6
- TN：0
- FP1：90
- FP2：2
- FN：22
- accuracy：`0.05`
- precision：`0.061224`
- F1：`0.095238`

### 修正版Epoch 3

- TP：38
- TN：1
- FP1：0
- FP2：1
- FN：80
- accuracy：`0.325`
- precision：`0.974359`
- F1：`0.484076`
- val loss：`0.00028191`
- checkpoint SHA-256：`8715203B396FBABE82CB99E11AD3F2C6137E892C66BF664A8C45836040E7C56D`

Epoch 3の独立評価は学習中の評価と完全に一致した。

## 現在の解釈

追加学習によって、正解位置とは異なる場所への反応であるFP1を90から0へ減らし、TPを6から38へ増やした。

誤った座標が後段の軌道や統計へ混入するリスクを下げられた点は肯定的に評価する。

一方、公式しきい値0.5ではFNが80枚残る。次はFNを一律に見逃しと扱わず、生ヒートマップの反応を調べる。

## 次に検証する仮説

### 仮説A：しきい値不足

FNフレームでも正解位置付近へ反応しているが、ヒートマップ最大値が0.5未満である。

この場合、しきい値を下げることでFP1を大きく増やさずTPを増やせる可能性がある。

### 仮説B：位置特徴不足

FNフレームの最大反応位置が正解位置から離れている。

この場合、しきい値を下げるとFP1が増えるため、追加データ、学習率、epoch数、モデル構成などを再検討する必要がある。

## 次回の作業順序

1. Epoch 3 checkpointを固定する
2. val 120フレームの生ヒートマップを取得する
3. 各フレームの最大値と最大反応位置を保存する
4. 正解座標との距離を計算する
5. 公式しきい値0.5の分類を再現する
6. 複数しきい値でTP・FP1・FP2・FNを集計する
7. FN 80枚を反応強度と位置誤差で分類する
8. 重点フレームを元画像へ可視化する
9. precisionを維持しながらTPを増やせる範囲があるか判断する
10. 結果から次の改善実験を選ぶ

## 分析上の注意

公式しきい値0.5の結果を主結果として維持する。

valを見ながら選んだしきい値を、同じvalに対する最終性能として過度に評価しない。

しきい値変更によってTPが増えても、FP1・FP2が同時に増える可能性がある。TPだけを見て改善とは判断しない。

今回のvalは同じ元動画と撮影環境であり、負例も2枚しかない。未知環境とボールなし判定能力は別途評価する。
